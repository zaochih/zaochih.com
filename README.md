# about.zaochih.com

Astro + Tailwind CSS static profile site.

## Setup

```bash
npm install
```

## Get started

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Learn more

- [Astro documentation](https://docs.astro.build/)
- [Tailwind CSS documentation](https://tailwindcss.com/docs)
